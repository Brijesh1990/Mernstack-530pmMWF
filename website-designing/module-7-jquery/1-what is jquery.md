# what is jquery ?
  1. jquery is a client side scripting language
  2. jquery is a library of javascript 
  3. jquery is also called inside of <head> and <body> using script tag
  4. jquery is called via its **CDN (content delivery network)**
    ## There are 2 types of CDN 
    1. Offline CDN 
    2. Online CDN 

  5. jquery starter using its method ....

     ```
     <script>
      $(document).ready(function(){
         statements;        
      })

      or 

      jQuery(document).ready(function(){
         statements;        
      })


     </script>    
     ``` 


# how to call jQuery 

  1- online CDN 
  2- offline CDN
