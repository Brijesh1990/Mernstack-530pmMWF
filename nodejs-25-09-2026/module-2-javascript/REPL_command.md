# REPL in JavaScript

REPL stands for **Read-Eval-Print Loop**. It is an interactive command-line environment where JavaScript code can be entered and executed immediately.

## How REPL Works

1. **Read**: Reads the JavaScript code entered by the user.
2. **Eval**: Evaluates or executes the code.
3. **Print**: Displays the result.
4. **Loop**: Waits for the next command.

## Example Using Node.js

Open a terminal and type:

```bash
node
```

Then enter JavaScript commands:

```javascript
> 5 + 3
8
> const name = "JavaScript"
> console.log(name)
JavaScript
```

The Node.js REPL is useful for testing small pieces of JavaScript code, checking results, and learning the language quickly.

To exit the Node.js REPL, press `Ctrl + C` twice or type `.exit`.
